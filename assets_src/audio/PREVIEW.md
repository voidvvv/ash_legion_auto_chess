# 音频最小集 · 试听清单（6 SFX + 1 BGM）

> 本次交付**没有人耳试听环节**（代理无听觉）：以下"试听重点"是给人审的检查表；机器侧验收见 `manifest.md`（时长/峰值/响度/哈希）与合成参数。
> 已按 `docs/spec_plan/quality_v2/stage1_design.md` §1.2 裁切：hit 0.12s / cast 0.33s / kill 0.30s / victory·defeat 1.50s / upgrade 0.58s；首尾 4–5ms 淡入 + 8ms 淡出。
> 建议按下面顺序连续试听，每条之间留 0.5s 静默。

| 顺序 | 文件 | 时长 | 类型 | 试听重点 |
|---:|---|---:|---|---|
| 1 | `sfx_hit.ogg` | 0.12s | 命中 | 0.12s 是否"脆"而不是"没声"；连放 10 次（140ms 间隔）是否刺耳；与 kill 是否能一耳朵区分 |
| 2 | `sfx_kill.ogg` | 0.30s | 击倒 | 是否有"结束感"（比 hit 更重、更闷）；0.30s 是否够收住；会不会被误听成又一次普通命中 |
| 3 | `sfx_cast.ogg` | 0.33s | 施法 | 上扫频起势是否清楚；0.33s 裁切是否把"魔法尾音"切太硬；是否太像激光枪 |
| 4 | `sfx_upgrade.ogg` | 0.58s | 升星/合成 | 双 ping 是否听得出"上行"；金币层是否被盖住；是否足够"值得截图" |
| 5 | `sfx_victory.ogg` | 1.50s | 胜利 | 大三和弦是否明确"赢了"；1.5s 是否太短/太急；与结算横幅节奏是否匹配 |
| 6 | `sfx_defeat.ogg` | 1.50s | 失败 | 下行小调是否"沉"而不"悲情过度"；低通是否太闷；与 3 次机会制的挫败感是否匹配 |
| 7 | `bgm_battle.ogg` | 120s | 战斗 BGM（额外项） | 循环接缝是否可闻；低频是否与 SFX 抢；与 0x72 灰阶单位 / Golden UI 暗木石调性是否协调；120s 是否腻 |

## 人审检查表（建议逐项打勾）

- [ ] **hit vs kill**：闭眼随机播放 10 次，能 90% 以上分清"普通命中/击倒"。
- [ ] **cast 辨识度**：在 BGM 播放时仍能听出"有人放技能"；0.33s 裁切后起势是否还在。
- [ ] **victory / defeat 情绪**：不看画面，能听出哪个是赢、哪个是输。
- [ ] **upgrade 上扬**：与 hit/kill 相比有明显"向上"的方向感。
- [ ] **BGM 循环**：连续循环 3 遍，接缝处没有"咔"或明显断层。
- [ ] **混音**：按 codex 的音量表（hit 0.24/0.58、cast 0.68、kill 0.60、victory/defeat 0.80、upgrade 0.68）播放时，BGM 不抢 SFX；连续命中不糊成噪声墙。
- [ ] **风格统一**：4 条合成 stinger 与 2 条 Kenney 拟音放在一起，是否像"同一个游戏"；若割裂，优先换合成音色，不要换拟音。

## 已知风险（供人审重点听）

1. **合成 stinger 的"chiptune 感"**：三角波+正弦是刻意贴像素风；如果主设计师想要更"管弦/史诗"，这 4 条需要重做（Kenney 包内没有合适的胜/败长音）。
2. **0.12s 的 hit 可能过短**：codex 要"干脆短脉冲"，但 0.12s 在 2× 战斗速度下可能听不清；若实机太弱，优先把文件恢复到 0.14s（仍在上限内），不要靠调大音量。
3. **cast / kill 被裁到 0.33 / 0.30s**：源 WAV 的尾巴被切掉，若实机觉得"收得太硬"，把 `build_audio_miniset.py` 的 `atrim` 放宽到上限（cast 0.35 / kill 0.32）再重建。
4. **upgrade 的金币层**：`handleCoins2` 只有 0.34s，叠在 0.58s 的合成层下；若听不清"金币"，把金币层 +3dB。
5. **BGM 接缝**：源作者标注 002 为 continuous loop，本机未做交叉淡化；若引擎里听到接缝，优先在引擎侧加 30–50ms 淡化，不要改源。
6. **短音 LUFS**：hit/cast/kill <0.6s，EBU R128 报 -70 是测量限制，不是静音；以峰值/RMS 为准。

## 试听顺序的"故事线"建议

`hit → kill → cast → upgrade → victory → defeat → bgm`：先听战斗三件套（命中/击倒/施法），再听成长一件（升星），再听结算两件（胜/败），最后听 BGM 与前面所有音效的共存。这样最容易判断"这套声音是不是一个游戏"。
