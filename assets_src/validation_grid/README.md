# 16 格验证盘（批 2 前置 · 非成品）

> 2026-11-22 ｜ 目的：验证“0x72 身体 + 武器/服饰剪影 + 6 档灰 + 星级 tint”能否让 **4 族 × 4 职业** 在 24px 下同时可辨。
> 状态：**验证材料，不是批 2 成品**；未复制进 `assets/art/units/`，不影响当前游戏。

## 1. 组成

- 4 个代表身体：`orc_warrior`（兽人）、`wogol`（野兽）、`skelet`（亡灵）、`ogre`（巨人），取自 0x72 包，走 pilot 同款 6 档灰 + 32×32 + 脚底 y=26 管线。
- 4 套职业剪影（验证用粗模，非最终美术）：

| 代号 | 职业 | 剪影线索 |
|---|---|---|
| W | 战士 | 左侧 7×8 尖底盾（浅灰面 + 深灰十字）+ 右侧 6×6 斧头与 3px 斧柄 |
| M | 法师 | 右侧 3px 法杖 + **7×7 杖头球 + 4 个星芒 + 新月托架**；有头部空间时加 **13px 宽檐尖顶巫师帽**（ogre 无空间，仅法杖 + 肩部符文） |
| R | 游侠 | 左侧 3px 弓弧 + 弦 + 箭；右侧 5×7 箭袋 + 3 个箭头 |
| A | 刺客 | 头顶深色低兜帽（不遮脸）+ **短而宽的匕首**（3px 刃 + 5px 护手 + 柄头，刃口下移至躯干） |

- 身体保持原种族剪影；武器/服饰可覆盖身体边缘（`Set-Px` 允许覆盖），以便看起来“持握”而不是漂浮。

### 种族标记（class-independent）

| 种族 | 标记 | 目的 |
|---|---|---|
| orc | 保留源图獠牙，不叠加（2×2 白块会读成白眼睛） | 与 wogol 的嘴/骷髅眼窝区分 |
| wogol | **突出的口鼻**：5×3 深色轮廓 + 3×2 浅色内芯 + 1px 深色鼻头 | 让中等体型有“兽”的身份线索；帽/兜帽不遮 |
| skelet | **下颌线** 1px（不加 2×2 眼窝，避免读成机器人） | 保留骷髅头识别 |
| ogre | **4×2 双肩甲 + 7×2 腰带（2×2 亮扣）**（不用角，避免与 wogol 耳混淆） | 大体型的“巨人”身份，非战士格也保留 |

## 3. 校验

- 16/16 脚底 y=26；32×32；alpha 二值（0/255）。
- 单帧 ≤10 色（身体 6 档灰 + 道具 3~4 档灰；正式批可压回 ≤6~8）。
- 生成脚本：`assets_src/tools/make_validation_grid.ps1`（无随机数，重跑一致）。

- **round-1 外部盲测未过线**：种族 10/16、职业 11/16（法师 2/4；wogol 2/4、ogre 2/4）。
