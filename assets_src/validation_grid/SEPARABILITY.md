## 3. 逐类/逐族结论

### 3.1 职业

| 职业 | 主线索 | 24px 可读性 | 风险 |
|---|---|---|---|
| 战士 W | 尖底盾（7×8）+ 斧头（6×6）+ 斧柄 | **高** | 盾在 24px 可能被读成“圆包”；斧头与盾同时存在时无歧义 |
| 法师 M | 高出头顶的 3px 法杖 + 5×5 杖头球 + 尖帽 | **高** | 巨人无帽（头顶空间不足），只靠杖；杖头球不能丢 |
| 游侠 R | 3px 弓弧（16~18px 高）+ 弦/箭 + 5×7 箭袋 | **高** | 弓必须保持 ≥3px 宽；1px 弓在 24px 会消失 |
| 刺客 A | 深色低兜帽 + 斜跨躯干的大匕首（刃尖伸出身体） | **中** | 单刃不如弓/斧“外扩”；若外部盲测失败，优先改成双刃 X 或加面罩 |

### 3.2 种族

| 种族 | 身份线索 | 加道具后是否仍可辨 |
|---|---|---|
| 兽人 orc | 方头、白獠牙、宽肩 | 是（盾/斧/杖/刃都在两侧或躯干，不遮头） |
| 野兽 wogol | 佝偻、条纹、体型最小 | 是（道具不改变轮廓主体） |
| 亡灵 skelet | 骷髅头、细腿 | 是（兜帽只到头顶上方，不遮眼窝；斜刃不遮头） |
| 巨人 ogre | 19×25 大体型、宽身 | 是（道具相对偏小，但轮廓最大，反而最好认） |

## 4. 外部盲测协议（建议主人/claude 执行）

1. 打开 `previews/blind_24_unlabeled.png`，**不要**先看 `BLIND_KEY.md` / 本文件。
2. 找 1~2 位未看过设计的人，逐格回答：种族（orc / wogol / skelet / ogre）+ 职业（战/法/游/刺），可记录每格用时。
3. 对照 `BLIND_KEY.md` 计分：
   - **通过线**：种族 ≥14/16 且职业 ≥14/16；每个种族 ≥3/4；每个职业 ≥3/4。
   - 若职业 13/16 但刺客 2/4 → 不通过（某一类塌陷比总分更危险）。
4. 若通过：武器/服饰剪影路线可进批 2（仍需等 R8 游戏内替换测试）。
5. 若不通过：
   - 刺客 <3/4 → 改双刃 X / 加面罩 / 兜帽加深，再测；
   - 法师 <3/4 → 杖头球加大到 6×6、帽尖加高；ogre 法师加肩部符文或杖顶旗；
   - 战士 <3/4 → 盾加大到 9×10、斧头改成更宽的月牙刃；
   - 游侠 <3/4 → 弓加粗到 4px、箭袋加 1px 高对比描边。

---

## 5. 结论

- **作者自读：条件通过。** 16/16 种族、16/16 职业可辨；4 个刺客格为“中”把握，是最可能的外部盲测失败点。
- **正式结论待外部盲测。** 本盘证明“0x72 身体 + 武器/服饰剪影 + 6 档灰 + 星级 tint”在 24px 下有可读性，但不足以单独宣布达标。
- 本盘道具为**验证粗模**（几何形状，非最终美术），批 2 正式版需按 24 子名字重绘/细化；身体与道具的锚点、配色、≤8 色合并也要在正式批统一。
