①主循环 —— 每个逻辑 tick 的四个固定阶段

四个阶段按序执行，永不改变；一切同 tick 冲突由「单位 id 升序遍历」决胜。

㈠ 状态推进
  • DOT 每 1s 心跳（真伤、可致死 → 直接进清扫名单）
  • 持续时间递减、控制倒计时
㈡ 逐单位行动
  • id 升序，跳过清扫名单者
  • 执行决策链（见 ②）
  • 每整 2s：全局索敌重评估
㈢ 死亡清扫
  • 统一标记死亡、腾格
  • 亡语 / 掉落钩子预留
㈣ 胜负判定
  • 敌全灭 → 胜
  • 我全灭 / 60s 超时 → 败
  • 否则进入下一 tick
↻ 未分胜负 → 下一 tick（循环往复）
H 语义三原则：① 伤害立即落地——后行动者看到的是最新 HP（治疗能救本 tick 刚被打残的人）；② HP ≤ 0 但尚未清扫的单位，本 tick 仍可行动、仍是合法目标——互秒由此成立；③ 攻击已清扫目标才会扑空，溢出伤害作废。

②单位决策链 —— 阶段㈡内部（每单位每 tick，自上而下）

纯函数优先链，不是行为树；「是」即向右执行并结束本 tick 行动，「否」向下坠落。

③攻击出手与两类弹道

出手瞬间先 roll 暴击（普攻 20% · ×1.5）并冻结载荷；伤害在「命中时」落地，能量也在命中时结算。

近战即时 MELEE_INSTANT
  • 出手 = 命中，无飞行过程
  • range = 1 单位适用
锁定弹 HOMING不可阻挡
  • 指定目标，追踪其当前所在格
  • 目标被清扫 → 落空消散（无伤害、无能量）
  • 用于：远程普攻 · NUKED · AOE（命中点爆炸）
直线弹 LINE可被阻挡
  • 发射时定向，不追踪
  • 被路径上第一个敌方单位挡下并命中
  • 出界 / 达射程上限消散
  • 用于：STUN（直线冲击）等

补充：弹道连续坐标飞行（不占格、互不碰撞），全局速度 6 格/秒；战斗结束在途弹道全部消散；技能不暴击（暴击为普攻专属）。

④技能施放 —— 具名技能（形状 × 效果 × 载体）

能量过百就地施放：无施法时间、无公共 CD、不清攻击计时。技能是 skills.json 中的具名资产（暴走 / 群体治疗 / 超远程狙击…）；数值幅度随星级 ×(1 + 0.5×(星−1))，状态时长不缩放。旧六模板退役为组合预设。

三步执行
① 形状解析目标集合 → ② 载体投送 → ③ 逐效果走既有管线（伤害/治疗/状态）
形状 Shape × 6
SINGLE_TARGET / SELF / LOWEST_ALLY / ALL_ALLIES / AOE_1 / ALL_ENEMIES（Boss 演出）
效果 Effect × 4
DAMAGE / HEAL / SHIELD / APPLY_STATUS——每技能 ≤ 3 条，可自由组合
载体 Delivery × 3 · 见 ③
MELEE_INSTANT 即时 / HOMING 追踪不可挡 / LINE 直线可被敌挡
例「暴走」 · 狂战士
SELF + [ATK_UP 30% ＋ ASPD_UP 30%]（8s）——单技能双状态
例「群体治疗」/「星陨」
ALL_ALLIES + HEAL 25% ／ ALL_ENEMIES + DAMAGE 1.8（最终 Boss）

⑤异常状态统一框架（ActiveStatus）

四类框架规则
  • 控制类（STUN…）：决策链第①步即跳过，能量冻结
  • 持续类（BLEED/REGEN）：1s 心跳；DOT 真伤可致死、不触发受击回能
  • 属性修改类（ATK_UP/SLOW…）：进修正管线 (基准+ΣADD)×(1+ΣPCT)，状态集变化时重算缓存
  • 叠加：同 type 不叠加、刷新时长（取更长）；不同 type 独立生效
  • power 取施放者快照，不追踪后续变化
三个入口 · 一个 StatusSystem
  • 技能 JSON（STUN / BUFF）
  • 装备（龙心 = REGEN）
  • 羁绊（兽人 6 = 开局 SHIELD）
  • 状态随单位死亡销毁

⑦战斗出口

🏆 胜利 → RESULT宝箱内容 roll（RNG 第③消耗点）→ PickChest 三选一 → 非最终轮进下一轮 / 第 25 轮通关演出
🛡️ 失败 / 超时 → SHOPPING 同轮重试BattleUnit 整体丢弃 · 敌阵不变 · 名单无损；连续失败第 3 次起怜悯 +1 金（封顶 +3，零棋子战败不计）
确定性收口：战斗内随机仅暴击判定一处（RNG 第④消耗点，按发射序消耗）；弹道飞行、索敌、移动、技能全部为确定函数——同名单 + 同种子 = 同一场战斗。
