移动 = 贪婪步自动走位（MovementSystem），玩家控制权全部在战前（侦察→布阵→开战），效果却设计在战中
已否路线（用户裁决关闭，仅留档）
① 全员固定 → 滑向《背包乱斗》 最近对位距离 2 > 近战 range 1 → 近战全废；够不着 → 60s 超时判负；移动 / 索敌 / 弹道三系统悬空。
启发保留：位置触发 = 强构筑感（低密度版用路线 A 实现）。
② 我固定 · 敌移动 → 滑向《植物大战僵尸》 玩家侧移速收益全废（刺客 / 野兽羁绊）；敌方"排队走过来"使敌阵站位信息贬值 → 侦察价值砍半。
启发保留：固定 vs 推进的对抗可作为棋子子类存在（路线 C），不能成全场规则。
逃逸路线（不消灭移动，把确定性还给格子）
A 开战快照光环 开战瞬间按初始站位结算邻接效果，之后不随移动变化。
控制点：布阵期（谁挨着谁）成本 低-中
咬合双实体快照架构；顺手销账"光环装备待 schema 扩展"旧债。
C 不动子类棋子（图腾 / 驻守单位） immobile 属性：全员可动、唯独它不动——天然空间锚点；仍占格、仍可被攻击索敌。
控制点：布阵期（放哪就在哪）成本 低(机制)+中(内容)
加载校验禁止"纯近战不动棋"（moveSpeed=0 且 range<2）。
B 持续地面区域 效果挂格子不挂棋子，踩上即生效（持续 APPLY_STATUS）。
控制点：布阵期 + 路径预判成本 中-高
敌人路径可推演（确定性）→ 拒止 / 分割 / 诱导 = "不用控制也能控制"。
雏形：毒雾弹（AOE_2 + POISON）区域化；主要风险：贪婪步遇阻罚站 → 撞 60s 超时。
