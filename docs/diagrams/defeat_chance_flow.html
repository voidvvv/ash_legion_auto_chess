    A[判负 全灭/超时/投降] --> B["onBattleOver: defeatCountPerRound +1（零棋子照扣）"]

    C -- "1~2 且上场>0" --> D[公式构造败箱 二选一 零RNG

挂 pendingChest origin=DEFEAT]
    C -- "1~2 且零棋子" --> E[无败箱 横幅
点击任意处重试 · 剩余机会 N]
    C -- "3 机会耗尽" --> F[无败箱 横幅
机会耗尽 · 远征失败]
    D --> G[ChestDialog「战败补给」二选一
PickChest 唯一出口
横幅点击/3s 均被 pendingChest 守卫拦截]
    G --> H[continueAfterDefeat
战斗态丢弃 · 回 SHOPPING 同轮重试
round/敌阵/商店不变]
    E --> I[横幅 3s 自动 / 点击] --> H
    F --> J[横幅 3s 自动 / 点击] --> K["endRun(DEFEATED)
熟练度 = 轮x3（同 ABANDONED）"]
    K --> L[RUN_END · RunEndPanel「远征失败」
restart 同英雄同场景新 seed]
    H --> M[进 SHOPPING 首帧写快照
defeatCountPerRound 入档 · 续玩不重置]
    N[胜局领箱推进新轮] --> O[defeatCountPerRound 清零]
判负时状态机会计数pendingChestRESULT 出口去向
上场 > 0，第 1/2 败+1（→1 或 2）败箱二选一（零 RNG）PickChest（唯一出口）回 SHOPPING 同轮重试
零棋子，第 1/2 败+1（→1 或 2）null横幅 3s / 点击回 SHOPPING 同轮重试
任意（含零棋子/投降），第 3 败+1（→3）null横幅 3s / 点击endRun(DEFEATED) → RUN_END
