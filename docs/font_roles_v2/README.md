## 结论

- 三种字面在实机可区分：标题黑体（无衬线）、正文楷体（笔锋/连笔感）、UI 宋体（衬线）。
- 字号整体下调：标题 24→20、UI 12→10、正文 9→8.5（虚拟 UI px）；默认 2× 窗口下
  标题 40px / UI 20px / 正文 17px 物理像素，正文在 640×360 的 2× 窗口内仍可读。
- 无字体缺失方块、无控制台字体告警；抽屉滚动、悬停卡换行、页签切换均正常。
- 截图仅为视觉核验，未修改主人正在运行的预览进程；验证实例在截图完成后已退出。
