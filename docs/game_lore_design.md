## 一、High Concept（高概念）

**《余烬军团》** 是一款像素风单机自走棋肉鸽游戏：

> 熄星之夜后，黑潮吞没大陆，星辰一颗颗熄灭。你是一名 **执棋者**——能用“战棋之约”将佣兵与部族凝聚成军团的最后传人。从灰烬中召集杂牌军，穿过荆棘林地、亡者墓穴与霜之峰顶，在星辰彻底熄灭之前，把光点回夜空。

---

## 二、世界观

### 2.1 熄星之夜
大陆 **维斯佩（Vesper，古语“晚星”）** 曾是星辉照拂的土地。三年前的冬至夜，夜空中最亮的 **导星** 无声熄灭，随后是第二颗、第三颗……星辰熄灭之处，大地被 **灰烬之潮**（简称“烬潮”）侵染：草木荆棘化、亡者不安眠、巨人性情狂乱。潮水所过之处不是毁灭，而是**遗忘**——颜色、名字、歌声，都被灰烬一点点抹去。

### 2.2 执棋者与战棋之约
旧王国曾有一支 **执棋者团**，他们不亲自挥剑，而以 **军旗与棋盘** 指挥战团：布阵、调度、把控时机。他们的核心秘术是 **战棋之约**——

> 「以金为誓，以旗为约。你为我而战，我不令你赴死。」

战棋之约有三条古老条款，是全部核心机制的叙事根基：

1. **金币即誓约定金**——佣兵与部族战士闻金而来，只为守约者而战（→ 商店雇佣、纯宝箱经济：灰烬大陆货币紧缩，唯有战利品是硬通货）
2. **败退不死**——旗下战士战败只会“退场”，整军再战（→ 失败原地重试：撤退、重整、再战，敌阵依旧，打法由你）
3. **心神有限**——执棋者能同时维系的誓约数量有上限，唯有声望与成长能拓宽心神（→ 人口上限与棋手等级）

### 2.3 星辰即进度
每净化一片区域，夜空中就有一颗星被重新点亮。**世界地图上的星数 = 大陆的解放进度**（→ 通关森林→解锁墓穴的场景解锁结构，并获得一个贯穿全局的视觉目标：把夜空一格一格点亮）。

## 三、剧情框架（三章 + 尾声）

单局 = 一次远征（一个区域、固定 25 轮，Boss 节点第 7/15/25 轮）；三区域全部点亮即达成“现版本通关”，尾声埋下真正的潮源伏笔。

### 第一章 · 翡翠林地（森林）
**剧情**：远征自大陆西缘开始。曾是精灵与游侠乐土的翡翠林地最先被侵染，野兽狂化、古树长出荆棘。玩家在林地边缘召集第一批佣兵，一路清剿至林心。

- **敌人倾向**：狂化野兽 + 堕落游侠（高速低血，对应 GDD 7.4）
- **第 7 轮 Boss**：**荆棘之母**——被烬潮寄生的世界树苗，藤蔓与荆棘从它的躯干里生长
- **第 15 轮 Boss**：**独眼猎神**——堕落的前游侠领袖，射出的箭会扎根发芽
- **终轮 Boss（第 25 轮）**：**荆棘之母·真体**——剥离伪装的烬潮容器
- **通关演出**：林地中央的第一颗星重新亮起，草木褪去灰烬色
- **叙事钩子**：垂死的荆棘之母低语：“潮水后面……有眼睛在看着你们。”（引向墓穴：灰烬流向了旧王国的地底）

### 第二章 · 亡者墓穴（墓穴）
**剧情**：灰烬流入地底，铁冠丘陵下旧王国的历代国王不安眠。亡灵并非邪恶——他们只是**忘了自己是谁**，在黑暗里重复生前的执念。执棋者的战棋之约对亡灵同样有效：唤醒他们残存的记忆，即可收编为麾下。

- **敌人倾向**：亡灵 + 黑暗法师（吸血 / 减抗）
- **第 7 轮 Boss**：**守陵巨像**——被错误命令驱动的石像卫兵
- **第 15 轮 Boss**：**双生巫妖**——共享一颗心脏的兄弟法师
- **终轮 Boss（第 25 轮）**：**白骨大公**——旧王国最后的摄政王，死后仍在无人可守的国库里数着不属于他的金币
- **专属棋子**：**死亡骑士**——大公麾下最先找回自我意识的骑士；区域通关后，他寻求赎罪，出现在雇佣池中（对应 GDD 7.4 专属棋子设定）
- **通关演出**：墓穴穹顶的星图浮雕亮起
- **叙事钩子**：大公的记忆碎片指向北方——灰烬逆流而上，霜峰之顶，“那颗坠落的星还活着”。

### 第三章 · 霜之峰（雪山）
**剧情**：导星并未熄灭，而是**坠落**在北方霜峰。烬潮自星骸向外扩散，严寒与遗忘一同冰封山径。巨人族并未全然堕落——反抗军仍在峰腰苦战，他们将成为最强大的盟友。

- **敌人倾向**：狂乱巨人 + 灰烬战士（高护甲 / 控制）
- **第 7 轮 Boss**：**霜啸雪怪**——由冻毙远征军的执念凝成的风暴
- **第 15 轮 Boss**：**断星者·格罗姆**——第一个触碰星骸的巨人王，臂膀已半烬化
- **终轮 Boss（第 25 轮）**：**星骸守卫**——环绕坠落导星自我复制出的灰烬圣骑士团
- **专属棋子**：**冰霜巨人**——反抗军派来的援军使者，可被雇佣
- **通关演出**：三颗星连成一线，导星的光在峰顶微弱地搏动——它还活着，但潮源不在此处

### 尾声（通关后伏笔，后续版本）
> 星辰已亮三颗，但导星的光芒依然微弱。它的残躯指向大海的方向——灰烬之潮真正的源头，在维斯佩之外。
> （为后续 DLC 场景 / 真结局预留，不影响当前版本闭环）

## 四、阵营与羁绊的叙事包装

大陆上的种族与职业即羁绊来源（对应 GDD units.json 的 race / class 双通道）：

| 羁绊 | 叙事形象 | 一句话气质 |
|------|----------|------------|
| 兽人 | 焰痕部族的雇佣兵，以烧伤的疤痕记录军功 | 越战越硬的正面铁壁 |
| 战士 | 各族老兵拼成的“执旗卫队” | 纪律与护甲 |
| 法师 | 熄星之夜后研究星辉残响的学者 | 危险的知识 |
| 刺客 | “拾星者”行会——专偷烬潮眼睛的暗巷传说 | 一击与撤退 |
| 野兽 | 翡翠林地中抵抗狂化的觉醒兽 | 高速与利爪 |
| 游侠 | 失去森林的精灵射手，箭术即乡愁 | 远程火力 |
| 亡灵 | 找回名字的铁冠旧部 | 打不死的执念 |
| 巨人 | 霜峰反抗军的山岳血统 | 移动的城墙 |

**羁绊的叙事解释**：同乡之谊（种族）、战友默契（职业）——并肩者越多，战号越响（→ 2/4/6 门槛：三伍成列、六伍成军）。

## 六、机制 ↔ 叙事对应表（本档案的核心价值）

每条核心规则都有世界观解释，美术与文案均据此取材：

| 游戏机制（GDD） | 叙事解释 |
|------------------|----------|
| 商店雇佣（5 槽 / 刷新 2 金） | 战棋之约：定金召募，闻金而来；刷新 = 换一批应征者 |
| 纯宝箱经济 | 灰烬大陆货币紧缩，战利品是唯一硬通货 |
| 宝箱三选一（金币 / 经验 / 装备） | 佣兵分赃传统：战利品由执棋者优先挑选 |
| 失败原地重试（1C-R） | 败退不死条款：撤退重整，旗未倒则军不散 |
| 重试时敌阵不变 | 侦察与沙盘推演：知己知彼，再战有备 |
| 3 合 1 升星 | 同乡三伍、百战成锐：并肩作战淬炼出的老兵 |
| 羁绊 2/4/6 | 同乡之谊与战友战号，人越多声越壮 |
| 能量满自动施放技能 | 战意：越战越勇，战意沸腾时放出绝技 |
| 装备可拆卸（B2） | 战利品归军团公有，随时重新分配 |
| 棋手等级 = 人口上限 | 心神有限：声望与成长拓宽能维系的誓约数 |
| 英雄熟练度解锁（3B） | 声望：你的传奇在大陆流传，强者慕名来投 |
| 专属传奇棋子（Lv.3 熟练度） | 只效忠于传奇英雄的成名人物 |
| 场景解锁 = 点亮星辰 | 世界解放进度，夜空一格一格亮起 |
| 战斗超时判负 | 潮势蔓延：僵持过久，灰烬将吞没战场 |

## 七、美术情绪基调（供像素风取材）

- **核心视觉对比**：温暖的军旗火光（橙金）vs 冷寂的灰烬世界（青灰蓝）——玩家的军队是画面中唯一的暖色源，“军团走到哪里，光就到哪里”
- **章节主色**：翡翠林地（病态的翠绿→净化后明亮的春绿）/ 亡者墓穴（青紫 + 骸骨白）/ 霜之峰（冷蓝 + 星光银）
- **棋子造型原则**：32×32 之内靠**轮廓剪影**辨识（兽人的宽肩、法师的尖帽、巨人的塔身），阵营用主色区分，星级用底座光芒表现
- **开场图 / 通关演出**：MVP 用静态像素卡图 + 一段文字；星点亮的瞬间是全局最重要的仪式感镜头
