## 〇 全局口径（v2 修订点加粗）

1. **档位替换制（P0-1）**：本稿所有档位按"全量效果"书写——达到更高档生效该档全部内容（数值已含低档等价物），与 `SynergyData.activeThreshold` / GDD §5.1 一致。叠加制备选见 §五。
2. **传奇门控（P0-3）**：军需官/圣鹿/颂者为英雄专属传奇（cost=3 锁死、不入 shopUnlocks、一局至多其一）；所有 6 档路线的主路径**不依赖传奇**，传奇为上位替代。
3. 池子 24 子、矩阵 4×4 行列各 6、费阶 10/9/5（暗影之刃 3→2 费、颂者回 3 费后重排）。**同名上场+备战合计上限 2**（第三张买入即自动 3 合 1，GDD §4.3，不可阻止——故双上阵路线最多 ×2）。
4. 红线与术语：零新增 RNG、60s 超时、×0.6 攻速、确定性回放沿用；全文"**可行动存活**"=未清扫且非倒地（清扫态=已移出战场；倒地态见 C7）。

### 3.4 点算保底问题的裁决与论证（P0-4 处理指引要求论证）

评审建议两案：无 <25% 目标时标记最近敌可放逐（保底）/ 降门槛。**本稿选择第三案：如实 0 下限＋设计接受**，论证：

1. **点算不是主引擎**。战斗级 D-S-P 表显示：死亡经济的主体是魂爆/白骨滩/绝响真伤与遗物层（占敌方总血 ~25~35%），点算只贡献 2~3 次放逐（~15%）；把点算做成保底不改变档位强度结论。
2. **保底会杀死"磨血循环"**。25% 线的价值在于玩家有意识地把敌人"磨进线"（毒、灼烧、双响新星都是压线工具）；无保底意味着压线打法有回报、放任不管有空转代价——这正是策略性。保底=每次死亡必移除一人，磨血循环与 25% 线的读法全部作废。
3. **克制完整性**。敌方（或玩家打镜像）靠护盾/治疗顶在 25% 之上是设计出来的反制；保底会让这条反制失效。
4. **调节杆预留**（不动设计，实测后启用）：若实测点算空转率 >50%（尤其分散站位局），可加"Boss 轮门槛 25%→30%"的轮次性微调——留主人终审，不进默认。
