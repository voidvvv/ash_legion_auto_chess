## 一、羁绊总表修订卡（仅列改动档；其余沿用 v2 §一）

**1. 兽人 (6) 旧疤——N10 公式写死**：
效果原文"每承受 3 次攻击获一层旧疤：攻击 +5%、护甲 +3"细化为——
- 有效攻击 = 基准攻 ×（1 + **0.05×旧疤层数** + 状态PCT/100）（乘算，随第二级有效值读取点走）
- 有效护甲 = 基准甲 + **3×旧疤层数** + 状态ADD（加算）
- 只认普攻直伤命中计数（DOT/真伤/反弹不喂层，同 v2 口径）

**3. 亡灵 名册——N10/N14 数值通道与回复统一**：

| 档 | 遗物每层（写死） |
|---|---|
| (2) | 攻 +4（**加算**，入攻击读取点）、生命上限 +20 **并立即回复 20** |
| (4) | 攻 +5、生命上限 +25 **并立即回复 25** |
| (6) | 攻 +6、生命上限 +30 **并立即回复 30** |

三档"立即回复"语义完全一致（N14 闭合）；遗物为加算通道、旧疤为乘算通道——两条计数器公式分列（N10 闭合）。

## 三、死亡触发审计修订（C6/C7/C8 + D-S-P 补充）

### C6 修订（N1：亡语源弹道特例）

空弦绝响两发同 tick 发射（同锁 HIGHEST_ATK 快照）；**第一发命中致目标 HP≤0 后，第二发在途遇目标清扫时：普攻/普通技能弹维持 Fizzled 现状（`ProjectileSystem.java:33-37`），亡语源弹道（deathrattle-born，载荷标记）改为按 LOWEST_HP 语义重选目标**。scope 写死：仅 ON_DEATH 来源弹道享有重选——工程改动点为 ProjectileSystem 消散分支按弹道来源分流（§五.7）。论证见处置总表 N1。

### C7 修订（N13：过滤点清单补全四处 + 状态时钟冻结）

倒地期间（1.0s）的豁免需要在**四个现有过滤点**加 downed 判定，否则倒地者仍被锁定/仍吃心跳：
1. `BattleSystem.java:250-259` currentTarget——现只查 isCleaned/side，倒地者仍是合法目标 → 补 downed 过滤；
2. `StatusSystem.java:73-76` tickStatuses——现只跳 isCleaned，倒地者 DOT 照跳/REGEN 照跳 → 补过滤并**冻结状态时钟**（DOT 计时与时长递减均暂停，防止倒地中被毒死=倒地中真死的规则灾难）；
3. `SkillExecutor` resolveTargets / enemiesWithin / lowestAlly——现查 isCleaned/isAlive（isAlive=!cleaned 不含倒地）→ 补；
4. TargetingSystem 索敌入口 → 补。
（⑤ 胜负判定与 aliveCount **不加**过滤——倒地计入存活是 N2 口径的要点。）

### C8 修订（N2：倒地窗口的名册边界）

继承者资格=本次清扫后**可行动存活**的友方亡灵——若某次亡灵真死发生于死骑倒地的 1s 窗口内且场上无其他可行动亡灵，**该层遗物作废**（人死账消的边界情形，如实写死，不做缓存递延）；但该次死亡的其他亡语（AoE/坏账/绝响/点算）照常结算——只有"给活人"的名册受资格限制。

### §3.2 D-S-P 表 v3 补充（N2/N6/N8/N9）

- **S 列口径换为"未清扫存活（含倒地）"**：两顺序表中 S 值不变（倒地仅发生在死骑第一倒，且他总会站起）；新增说明行——"死骑倒地窗口"：若第 5 名亡灵死于该 1s 内，末层遗物按 C8 作废，S 仍=1、⑤ 不判负——红线不破，只是末层收益落空（概率低、后果轻，如实呈现）。
- **峰值拆开（N6）**：顺序 B 的**当次伤害峰值=D=1**（魂爆 195，全场最高单次）；**累计收益峰值=D=4~5**（真伤累计顶点与遗物/续航集中段）。
