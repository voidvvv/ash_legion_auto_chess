## 附：itch 小人素材放置指引（T4 遗留，许可可核实后执行）

itch.io 直连不可达且作者镜像无 LICENSE，按"不伪造素材/许可"原则未入库。放置步骤：

1. 选 itch.io 免费小人包（许可须允许本项目用途），放置 36 个 PNG 到 `assets/art/units/`：
   - `unit_warrior_01_{anim}_{frame}.png`、`unit_ranger_01_{...}`、`unit_assassin_01_{...}`
   - anim 取值：`idle`/`walk`（各 2 帧）、`attack`/`death`（各 3 帧）、`cast`（2 帧），帧号从 0 起
   - 规格：32×32、透明底、朝右
2. 素材包自带 LICENSE 则复制为 `assets/art/units/LICENSE-<包名>.txt`，并在该目录 README.md 补记作者/链接/许可
3. 帧数不齐不必补画——缺帧自动回退占位（W-8 设计行为）
4. 放置后复验上方第 2 项
