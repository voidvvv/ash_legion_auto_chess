## ⓪. 病根诊断——它缺了什么，才不配叫"游戏"（玩法评审第一章）

> 主人补刀原话："这根本就不能叫做游戏，只能勉强叫做能够进去点点点的软件。"——本章先回答这句话，再谈清单。判据不是情怀，是定义：**游戏 = 玩家做出有后果的选择，系统给出可学习的反馈，且选择是排他的、代价是真实的。**"能进去点点点的软件" = 每次输入都有响应，但没有任何一次选择需要你付出任何东西。

**游戏性最小完备集诊断**：

| 要素 | 成熟游戏应有的形态 | 本作现状（锚点） | 判决 |
|---|---|---|---|
| 目标与目标感 | 玩家随时答得出"我现在要做什么、为什么" | 有终局目标（25 轮通关，GDD §2.1），但中途零子目标：每一轮的行动理由只有一句"变强去打下一轮"，而"变强"不可见（见成长行） | 形同虚设 |
| 反对与压力（有东西在阻止你） | 持续挤压：资源在流失、威胁在升级、时限可感 | 失败只扣本轮机会（败 1~2 还送补偿箱，GDD §2.2）；下轮机会清零重计；敌人强度一条直线（GDD §7.3）；60s 时钟存在但不可感——超时了才判你负 | **缺失** |
| 抉择与代价 | 选排他、选错疼、选对爽 | 买 A 还是 B 不疼（失败无成本 ⇒ 金币决策无重量）；摆哪不疼（无持久风险）；重试无限且敌阵不变 ⇒ 每个抉择都能"试到对"再正式开始 | 形同虚设 |
| 后果与反馈 | 结果可读、可归因、可学习 | 胜 = 一行"胜利"（`ResultBanner.java:56`）；败 = 黑框 + 一行字；无统计、无回放、无战后小结；战斗过程本身不可读（灰度+tint，见 P03） | **缺失** |
| 成长与可见性 | "变强"发生在玩家脸上 | 升星变色、羁绊改数字、人口 +1——全在数字层；局内无战利品、无增益、无进化时刻 | 形同虚设 |
| 规则一致、可学习 | 结算确定、可推演 | ✔ 达标：随机仅暴击、敌阵不变重试、纯函数结算——**全项目唯一达标的"游戏性"要素**（architecture §六） | 达标（被不可读性埋没） |

**病根论证**：把游戏性的心跳——"选择 → 后果 → 学习 → 再选择"——拆开看，每一环都在断裂：选择无信息（商店卡无羁绊标注，P18）→ 后果不可见（战斗不可读，P03/P12）→ 后果无代价（失败无成本，P14）→ 无代价则选择无重量 → 无重量则无目标感。于是它精确地成为主人说的那样：**每个系统都在"响应"你，没有任何系统在"要挟"你。**软件的体验是"输入 → 响应"，游戏的体验是"抉择 → 利害"——本项目工程上完成的正是前者。

更刺的一句：唯一达标的一环（确定性规则）反而在加重"软件感"。它让每一次重试都精确相同，等于把"游戏"推成了**可以无限试错的调试器**——确定性本来能成为"精确推演"的卖点，前提是可读性成立；可读性不成立时，确定性只负责让"重复"显得更重复。

**一句话**：它缺的不是内容量、不是打磨、不是素材——它缺**利害**。补上"会失去的东西"（E2）与"看得见的变强"（E1），再让后果可读（E3），它才开始是游戏。§E 的路线就是按这张诊断表开的方。

## 0. 总判

- **视觉（对准痛点①）**：问题不在"素材廉价"，在**这个项目从来没有做过"美术方向"这件事**——没有统一色板（GDD §9.1「选型待定」至今未做）、没有场景概念、没有特效规格。单位是 0x72 灰度帧加代码染色，界面是 Golden UI 另一套色盘，棋盘是三个纯色矩形。三套视觉语言互不相认。**换更好的素材救不了，这是方向重定级的问题。**
- **玩法（对准痛点②）**：当前结构里**失败几乎没有代价**（每轮 3 次机会、败 1~2 送补偿箱、敌阵不变重试），**成长几乎没有可见时刻**（升星变个色、羁绊激活改个数字），**中途没有任何意外**（25 轮固定、敌人强度一条直线、Boss 只是血多的怪）。紧张感=0 不是缺陷，是设计的必然结果——这套规则里没有任何东西逼玩家紧张。
- 一句话总判：**现在这是一个"能跑、能结算的规则引擎"，还不是"游戏"。缺的不是打磨，是感官层与动力层各一次重建。**

## B. 自走棋设计师：六大支柱逐项检查

| 支柱 | 现状（锚点） | 判决 |
|---|---|---|
| **核心循环爽点节奏**（买→摆→看打→结算） | 看打是唯一的核心消费环节，而它现在是：无声（P01）+ 无特效（占位爆点，P04）+ 慢速（×0.6 → 出手间隔 1.11~2.38s，GDD §6.7）+ 小字反馈（9px，P12）。整条反馈链只在"结算"那头有一行字 | **毁体验**：核心消费环节全面贫瘠 |
| **经济与决策深度** | 199 金全胜通关、结余 +39~59（GDD §3.2）——零容错设计已修成宽裕；但**失败无成本**（3 机会+补偿箱+敌阵不变，GDD §2.2）⇒ 金币决策没有"压力"作衬，买什么都不疼 | **显著减分**：决策的重量被失败保障抽掉了 |
| **战斗可读性** | 32px 灰度精灵 × 星级 tint（混色变暗）× 0.8 缩放；棋盘三块平色；无队伍标识、无伤害统计、无战后复盘。**玩家无法回答"为什么赢/输"** | **毁体验**：自走棋的第二核心消费是"看懂"，当前不可读 |
| **随机与掌控感** | 确定性战斗（随机仅暴击）+ 敌阵不变重试——掌控感的设计底子是好的；但确定性要靠**可推演**兑现，可读性不达标时确定性退化成"看腻了" | **方向对、兑现失败** |
| **成长反馈** | 升星 = tint 变金；羁绊 = 右侧面板数字；人口 = 格子变多。全部"数字级"，无一个"演出级"变强时刻；局内无遗物/增益/进化 | **显著减分**：成长发生了，但玩家看不见 |
| **新手前 5 分钟** | 引导 = 一句横幅文案；羁绊系统零教学；第 1 轮敌人 1 个；右侧羁绊面板开局是空的"-" | **显著减分**：没有第一个"啊哈"时刻 |

## D. 视觉专项：为什么"换更好的素材"救不了（美术方向重定级）

主人点名"廉价的开源素材"。要害不是素材贵贱，是**这个项目没有过"美术方向"**。证据链：

1. **三套视觉语言并存**：单位=0x72 灰度帧+`PalettePick` 占位哈希配色（32 色"手挑可区分色"，`PalettePick.java:16`，render §7.5 明确这是占位口径）；界面=Golden UI（深蓝灰石+暗金）；棋盘=`BattleRenderer` 里手写的第三个色板。GDD §9.1"全局统一 ≤32 色调色板（选型待定）"立项至今未做。
2. **灰度+tint 路线的辨识度天花板已被实测击穿**：24px 下灰度底+tint 无法承载种族辨识（盲测种族轴几乎全错），星级 tint 又整体压暗一档——"没有任何辨识度"是这条路线的必然，不是素材质量问题。
3. **特效层为零**：所有技能/亡语演出共用一个几何爆点占位——"毫无印象的特效"是准确的。
4. **场景层为零**：棋盘外是纯黑虚空，棋盘内是三块平色——"昏暗的界面"的来源。

**结论**：视觉需要一次**方向重定**，顺序建议：① 先锁统一色板与场景基调（1 张概念图 + 色板锁定，这是所有素材的母法）；② 重定单位表现方案（放弃"灰度+全局 tint"，改彩色原画 + 职业剪影/框色表星级，辨识度与成长可读性一起解决）；③ FX 与演出规格（技能/亡语/胜负三类最小集）。在此之前**不要**再采购任何新素材——方向没定，买什么都是下一轮"廉价素材"。

## E. 驱动力专项：25 轮缺了什么，roguelike 要素按投入产出排序

主人要的参照是"roguelike 的紧张刺激与成长感"。拆开是四件事，当前结构逐项对照（**本章即 ⓪ 病根诊断的处方**：E1/E2 补"利害与压力"，E1/E3 补"成长可见与后果可读"——先补最小集，再谈其他抛光）：

| roguelike 支柱 | 当前状态 | 判决 |
|---|---|---|
| **持续的失去**（血量/资源在流失） | 无任何持续池子：失败只扣"本轮机会"，下轮清零重计；败 1~2 还有补偿箱 | **张力源头缺失** |
| **成长可见**（每局能指出"我因为这变强了"） | 变强全在数字里：星级/人口/羁绊档位；局内无战利品、无遗物、无进化 | **成长不可见** |
| **抉择的重量**（选错会疼） | 失败无成本 ⇒ 金币抉择无重量；25 轮结构固定 ⇒ 无路线抉择 | **抉择无重量** |
| **随机变异**（每局不一样） | 仅商店与敌人组合随机；结构、事件、奖励全固定 | **变异不足** |

**roguelike 化路线，按投入产出排序**（⭐=建议优先）：

| # | 方案 | 补哪根支柱 | 投入 | 产出 | 说明与依赖 |
|---|---|---|---|---|---|
| E1 ⭐ | **精英怪战利品时刻**：每 3~5 轮插入精英/赏金怪，击杀掉"全局增益 / 单棋子进化 / 临时词条"三选一 | 成长可见 + 抉择重量 | 中 | 高 | **主人自己的原案**（mechanics_synergy_framework 讨论记录："特殊怪击杀后给特殊奖励：全局增益、单个棋子进化"）——设计已存在于讨论中，只差立项；复用现有 buff/装备系统与宝箱通路；"优先击杀目标"还给战斗加了即时决策 |
| E2 ⭐ | **压力池**：把"每轮 3 次机会"改成持续资源（如 10 点士气/沦陷进度，败一次扣 1~2，见底远征结束） | 持续的失去 | 中 | 高 | 直接制造紧张感的源头；与 3 机会制的"有限救助"哲学兼容（把每轮重置改成跨轮累积即可）；数值是最大工作量 |
| E3 | **战斗小结**：结算前显示双方输出/承伤/击杀三行 | 成长可见 + 可读性 | 小 | 中 | 确定性战斗下数据精确，实现便宜；让"为什么输"可回答 |
| E4 | **动态难度抉择**：备战期可点"挑战加强波"（敌 +1 档，奖励 +1 档） | 抉择重量 + 紧张 | 小~中 | 中 | 一个按钮 + 一个倍率；风险回报自选，roguelike 手感最廉价的一针 |
| E5 | **随机事件节点**：非战斗轮插入事件（三选一增益/代价事件/商店事件） | 随机变异 + 抉择 | 中 | 中 | 爬塔骨架已有（25 轮结构可插事件位）；文案与事件池是内容工作 |
| E6 | **Boss 机制化**：阶段/词条/登场演出 | 紧张 + 演出 | 中 | 中 | 复用 HFSM 预留；Boss 战才有 Boss 感 |
| E7 | **美术方向重定**（§D 三步） | 视觉痛点 | 大 | 高 | 与 E1/E3 并行立项不冲突；素材采购冻结至方向锁定 |
| E8 | **地图分支**（轮次路线选择） | 抉择重量 | 大 | 中 | 后置；等 E1~E4 验证驱动力回升后再投入 |
| E9 | **局外深化**（熟练度已有；解锁改规则型内容） | 长线动力 | 中 | 中 | 后置 |

**一句话结论**：先做 E1+E2+E3——它们共同把"输没有代价、赢没有感觉"这个根因翻转；视觉侧 E7 与之并行立项。在 E1/E2 落地前，其余打磨都只是在"无张力的循环"上抛光。
