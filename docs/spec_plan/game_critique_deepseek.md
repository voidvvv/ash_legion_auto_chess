## 0. 三句话结论（给赶时间的人）

1. **画面**：全屏平均明度 **5.9%–10.8%**，战斗画面 **99.2% 的像素明度低于 20%**；33 个单位全部是 CC0《DungeonTileset II》的 6 档灰 + 运行期 tint；技能特效文件 **0 个**。这不是"暗黑风"，是"关着灯用 Excel 做游戏"。
2. **玩法**：25 轮直路 + 每轮 3 次机会 + 失败补箱 + 卖出 100% 退款 + 每轮免费刷新——**所有决定都可以反悔，敌人打输了也不变**。自走棋的紧张感来自"不可逆的下注"，这一版把它全部拆掉了，只剩"宝箱三选一"。
3. **优先级**：先修"暗"和"乱"（布局/字体/明度），再修"没有下一次"（run 结构/不可逆决策/可见时钟），最后才是加棋子、加特效。现在直接加美术，会被现有布局吃掉；直接加棋子，只会让 25 轮更长。

# 第一章 玩法研究：自走棋为什么好玩，以及这一版为什么"没有驱动力"

## 1.1 先对齐：自走棋的四根支柱

| 支柱 | 玩家在买什么 | 代表机制 | 失去它会发生什么 |
|---|---|---|---|
| **构建（Build）** | "这一局我要把它拼成什么" | 羁绊、装备、星级、强化 | 每局都一样，玩家在"执行"而不是"创造" |
| **凑成（Payoff）** | "还差一张/还差 1 个羁绊"的悬念与兑现 | 2/4/6 羁绊点亮、三合一、关键装备 | 没有值得截图的一秒，玩完就忘 |
| **经济（Tension）** | "现在花还是再存一轮"的取舍 | 利息、连胜/连败、血量换资源 | 金币退化成"开箱计数"，没有策略 |
| **信息与博弈（Mastery/Discovery）** | "我读懂了环境，我赌对了" | 看对手、共享牌池、海克斯/强化 | 单机时变成"看动画"，没有对手也没有惊喜 |

Riot 在 TFT 首篇设计博客里把支柱写成 **Mastery / Playful Competition / Discovery**（精通、玩闹式竞争、发现），并明确说这是"从选英雄、优化羁绊、配装备到送他们上战场"的一整套乐趣 [来源](https://teamfighttactics.leagueoflegends.com/en-gb/news/dev/dev-design-pillars-of-tft/)。这三个词翻译成玩家语言就是：**我能变强、我能跟人斗、我能发现新东西**。本报告后面所有的"不好玩"，都能归到这三件事至少缺一件。

## 1.2 爽点的机制解剖：玩家说的"好玩"到底是什么

### ① 羁绊凑成的时刻 = 身份转变，不是数值 +X
- 玩家真正爽的不是"攻击 +18%"，而是"我这堆杂牌突然变成了一支**兽人军**"——是**身份**变了，队伍在视觉/听觉上要跟着变。
- 所以 TFT 每次羁绊升级都有全屏提示、音效、场上单位外观变化；这不是"包装"，这是爽点本体。
- **截图证据**：本作右侧"羁绊池"面板是一个空黑框，里面只有一个破折号——全游戏最核心的"凑成反馈"，在界面上连位置都没有。
- **反例**：本作羁绊只在结算里加属性，截图里没有任何"2 兽人已激活"的常驻面板，玩家凑成了也不知道。

### ② 三合一 = 赌狗时刻，需要"差一张"的悬念
- 三合一的爽来自"我差一张"的持续惦记，以及"合成了"的爆点；它必须配 **可见的进度**（还差几张）、**可听的兑现**（合成音/光柱）、**不可逆的代价**（合错了就没了）。
- 本作有 3 合 1（GDD §4.3），但卖出 100% 退款、每轮免费刷新，等于告诉玩家"随便合，反正能退"——**赌狗没有下注，就不是赌狗**。

### ③ 连败翻盘 / 经济抉择 = 自走棋的策略心脏
- TFT 的利息、连胜/连败奖励、升级/搜牌/存钱的三角，是每轮都在做的真实决策；"我血少了，要不要梭哈"就是紧张感的来源。
- 本作是**纯宝箱经济**：没有固定工资、没有利息、没有连胜（GDD §3.1 明确"没有利息、没有连胜"）。金币只从宝箱和卖棋来，收入曲线是公式写死的——玩家没有"经营"，只有"开箱"。

### ④ 海克斯/强化 = 让"每一局规则不同"
- TFT 官方在七周年访谈里把 **Augments（海克斯）** 称为转折点：第 6 赛季引入后，"我们第一次意识到这个机制会成为游戏不可分割的一部分" [来源](https://gamesbeat.com/teamfight-tactics-turns-7-riot-games-discusses-lessons-learned-and-the-road-ahead-exclusive-interview/)。
- 同一篇访谈里，官方承认第 5 赛季的 **Shadow Items（暗影装备）** 是"高调失败"：玩家讨厌**强制**的"福祸相依"，后来改成 **opt-in（可选）** 的风险回报 [同上]。这条教训极其重要：**风险必须是玩家主动选的，不能是系统强塞的**。
- 2026 年 TFT 的 Charms 系统，官方强调两点：**前期要有有趣的选项**、**长期下注仍然有效**，而不是后期只剩战斗数值 [来源](https://www.invenglobal.com/articles/23690/tft-developers-unreal-engine-is-just-the-beginning)。
- 同一篇访谈还提到 Set 12 的"66 血或 99 金换 3 星 5 费"这种"浪漫选择"，官方明确要保留这种 dopamine 时刻 [同上]。**玩家要的不是平衡，是"值得赌的一刻"。**

### ⑤ 单机时，爽点要靠"事件"和"仪式"补
没有真人对手，就没有"我赢了那个家伙"的社交快感。单机自动战斗必须用三样东西补：
1. **可见的成长**：每轮结束能看到"我比上一轮强在哪"（新单位、新羁绊、新装备、新强化）。
2. **不可预测的转折**：随机事件、精英战、诅咒/祝福，制造"这局跟上一局不一样"。
3. **仪式感**：Boss 登场、合成、羁绊点亮、结算页——给玩家"值得截图/录屏"的一秒。

## 1.3 常见"自走棋做得无聊"的死因

| 死因 | 玩家原话/现象 | 机制解释 | 来源 |
|---|---|---|---|
| **30 分钟一局 vs 休闲定位** | "一局太久，输了很亏" | 自走棋本质是休闲，但单局 30 分钟，时间成本与失败惩罚不匹配 | [腾讯《我们为什么不玩自走棋了》](https://syzs.qq.com/blog/default/20210430A0DE3O00) |
| **阵容同质化** | "一个版本能吃鸡的就那几套" | 内容池小 + 强度差 → 玩家被迫抄作业，发现感消失 | 同上 |
| **版本更迭 = 重新学习** | "每次更新像换了个游戏" | 用"高频大改"续命，学习成本劝退中间玩家 | 同上 |
| **抄袭与换皮** | "2019 年全是换皮" | 成熟玩法被快速复制，差异化不足，审美疲劳 | 同上 |
| **强制风险** | "暗影装备太恶心" | 玩家讨厌被系统强塞的负面效果；风险要 opt-in | [GamesBeat TFT 七周年](https://gamesbeat.com/teamfight-tactics-turns-7-riot-games-discusses-lessons-learned-and-the-road-ahead-exclusive-interview/) |
| **单机看动画** | "我就是在看他们打" | 没有对手、没有操作、没有中途决策 → 被动 | 行业观察（我的归纳） |

> 这六条里，本作目前**至少中了三条**（25 轮 20–30 分钟、24 棋子 6 羁绊的同质化风险、单机看动画），外加一条自创的"失败补贴"——把惩罚也消解了。剩下的"版本更迭疲劳/换皮"要等上线后才成立，现在不该拿来当借口。

## 1.4 单机自动战斗怎么活：Roguelike 化机制清单

### ① Run 结构：把"25 轮直线"改成"三幕地图"
《杀戮尖塔》的地图不是装饰，是**风险预算**：每幕十余层（第 1 幕 17 层）、从下往上分叉，玩家一旦选入口就只能沿连线走；幕中固定宝箱、Boss 前固定休整、Boss 从头像可见，精英/休整不会出现在最前几层 [来源](https://teemo.dev/game-design/slay-the-spire/systems/map-path-and-act-structure/)。这带来三个自走棋直路给不了的东西：
- **路径即决策**：血少走休整/问号，牌强走精英拿遗物。
- **Boss 可见**：玩家从第一层就知道要为什么做准备（"发现"与"规划"）。
- **结构保底**：不管随机成什么样，每幕都有宝箱、Boss 前都有休整（公平感）。

**照抄建议**：25 轮 → 3 幕 × 6–8 节点（战斗/精英/商店/事件/休整/宝箱），第 7/15/25 轮 Boss 改为"每幕末 Boss"，进幕前可见 Boss 头像与词条。

### ② 血量/资源压力：让玩家用"命"换力量
- 《杀戮尖塔》的休整：回血 or 升级，二选一；Act 4 的三把钥匙，每一把都要放弃一次正常奖励 [同上]。
- TFT 的"66 血换 3 星 5 费" [Inven](https://www.invenglobal.com/articles/23690/tft-developers-unreal-engine-is-just-the-beginning)。
- 本作的血量/机会是"每轮 3 次"，且败了还给箱子——**血不是资源，是免死金牌**。建议改成：机会全局有限（如 5 次/整局），或者用"腐化/侵蚀"做可见时钟，每轮推进一格，满了就终局。

### ③ 可见的时钟：单机必须有"再不走就死"的压力
没有 7 个真人对手在等你，就必须有一个**看得见的推进器**：波次强度曲线、地图上的追击者、每轮掉血、限时事件。TFT 的时钟是"其他玩家的血量"，单机要把这个时钟**画出来**（顶部进度条/世界地图上的红潮），否则玩家只会觉得"我在原地刷"。

### ④ 随机事件与抉择：改变规则，而不是加数值
- 事件应该是"三选一，选完这局规则变了"：比如"所有兽人 +1 攻击，但商店不再出精灵"、"本幕 Boss 血量 +30%，通关多一个传说装备"。
- TFT 的强化、金铲铲的 Charms 都是这个思路：**build 的方向盘**，不是数值补丁。
- 本作目前只有"宝箱三选一（装备/金币/经验）"，这是**资源选择**，不是**规则选择**；它不改变你怎么玩，只改变你数值多高。

### ⑤ 局外成长：解锁"新玩法"，不是"+25%"
- 本作：英雄熟练度 Lv.5，每轮 +3、通关 +60，升级给"专属加成"（如某羁绊效果 +25%，GDD §8.1）。
- 这是**刷时长**，不是**新内容**。玩家不会因为"再打 20 轮能把 +25% 变 +30%"而再来一局；他会因为"解锁了一个新英雄/新事件/新强化池"而再来一局。
- 建议：熟练度只解锁**新英雄、新起始遗物、新事件池、新难度词条**；数值加成放到"成就/图鉴"里当添头。

### ⑥ "再来一局"的钩子
| 钩子 | 参考 | 本作现状 |
|---|---|---|
| 短局（10–20 分钟） | Super Auto Pets 的短局节奏（产品形态观察） | 25 轮 20–30 分钟，偏长 |
| 快速重开 | 《杀戮尖塔》死亡即重开 | 有重开，但没有"这局输在哪"的复盘 |
| 每日种子/排行榜 | 《杀戮尖塔》Daily Run、TFT 双排 | 无 |
| 异步幽灵对手 | Super Auto Pets / Backpack Battles 的异步 PVP（产品形态观察） | 无，只有半随机 AI 池 |
| 结算故事 | 《杀戮尖塔》的 run summary | 无（截图里连结算页都没出现） |

> 说明：Super Auto Pets / Backpack Battles 的具体系统我没有拿到一手设计文档，这里只作为"异步对手 + 短局"的产品形态参照，不作为机制细节引用。

## 1.6 单机自动战斗"有张力"的机制清单（可直接排期）

### P0（不做就没有"再来一局"）
- [ ] **三幕地图**：每幕 6–8 节点，节点类型：战斗/精英/商店/事件/休整/宝箱；Boss 进幕可见。
- [ ] **不可逆决策**：每幕 1 次"三选一强化"（改变规则，不是加数值）；选定后本幕不能换。
- [ ] **全局有限机会**：5 次失败/局；失败不补箱，改为"失败后本幕敌人 -10% 血量"之类的**软保底**（让玩家能过，但不白拿）。
- [ ] **可见时钟**：地图上的"侵蚀"每轮 +1，满格终局；或每幕限时。
- [ ] **结算页**：本局 build 故事（成型羁绊、关键装备、最险的一战、输在哪）。

### P1（决定"好不好玩"）
- [ ] 利息/连胜/血量换金，三选一。
- [ ] 精英战掉"遗物"（规则型被动物品，如"三合一后额外获得 1 金"）。
- [ ] 事件池：至少 12 个事件，每个 2–3 个选项，有得有失。
- [ ] 每日种子 + 本地排行榜；异步幽灵对手（可选）。
- [ ] 6 个羁绊各配 1 个"6 羁绊专属机制"（不是纯数值），让"极致纯种"有身份。

### P2（决定"能卖多少钱"）
- [ ] 难度阶梯（Ascension）：每级加一个词条，不加纯数值。
- [ ] 英雄专属机制（不是 +25%）：如"开局多 1 个宝箱"、"商店必出 1 个野兽"。
- [ ] 图鉴/成就/皮肤。
- [ ] 每日挑战/周常种子。

# 第二章 视觉评审：逐张毒评 + 三条最致命

## 2.1 第一眼判档：像什么档次？

> **不是页游，不是独立游戏，更不是正版——像"LibGDX 教程第 2 天的 debug 场景"。**

- **页游**至少有立绘、光效、充值入口和一套"看起来很贵"的边框；本作没有。
- **独立游戏**至少有一个记忆点（一个角色、一种色调、一句标语）；本作去掉标题后，和任何 game jam 项目无法区分。
- **正版**要求主视觉、UI 语言、动效、音效四位一体；本作目前只有"能点的矩形"。

如果一定要给个档位：**引擎调试器 / 课程作业 / 内部自测版**。距离"能上 Steam 新品节"差的不是"再画几张图"，而是**主视觉、光照、信息设计**三件事。

**量化证据（像素采样，每 4 像素取一点）**：

| 截图 | 平均明度 | 明度 <20% 的像素占比 | 最大单色占比 |
|---|---:|---:|---:|

## 2.3 三条最致命视觉问题

### ① 昏暗不是风格，是"没有光"（对应主人原话"昏暗的界面"）

**证据**：
- 开局画面 `#0D0A14` 单色占屏 **79.4%**；商店界面 54.7%；战斗画面 **99.2%** 的像素明度 <20%，平均明度 **5.9%**。
- 棋盘只有两种颜色：暗红 `#422323`、橄榄 `#213323`；面板 `#202630`；主色几乎都在明度 8–25% 区间。
- 唯一亮的东西是白字和橙色边框——**亮部没有层次，暗部没有细节**。

**为什么这是致命的**：
- 人眼靠**明度对比**找焦点。全屏 90% 以上是近黑时，35 个同样暗的格子、同样暗的面板、同样暗的按钮会糊成一片，玩家找不到"我该看哪"。
- 暗色 UI 的正确做法是"**暗背景 + 中景层次 + 高光引导**"：背景压暗，面板抬亮，交互元素最亮，再用 1–2 个光源（火把/月光/魔法辉光）把视线拉到主体。本作是"全暗，连亮都没设计"。
- 这不是"调个色"能解决的：**没有背景图、没有投影、没有环境光**，所以暗部是"死"的，越看越像没加载完。

**最小修复**：
1. 加一张 640×360 的**场景底**（地面/墙/雾气/光斑），哪怕只是渐变 + 噪点 + 两三个光斑，也能立刻把"调试器"变成"场景"。
2. 建立**明度阶梯**：背景 10–15%、面板 20–25%、棋盘 25–35%、可交互元素 60–80%、文字 85–95%。
3. 棋盘加**投影/内阴影**，让格子"陷进去"，而不是像贴纸浮在屏幕上。

### ② 没有识别系统（对应主人原话"没有任何辨识度"）

**证据**：
- 33 个单位全部来自 CC0《DungeonTileset II》（0x72），**6 档中性灰 + 运行期星级 tint**（素材清单 §0 自述）。
- 12 个 UI 件全部来自 CC0《Golden UI》，"棕边 + 深蓝底"通用奇幻框。
- **0 个技能特效文件**；FX 规格是"单帧贴图 + 程序缩放淡出"（`art_asset_spec.md` §4.2）。
- 没有 Logo、没有主视觉、没有阵营色、没有图标语言；6 个羁绊在界面上没有任何颜色/图形身份。

**为什么这是致命的**：
- 玩家记不住任何一个单位，也说不出"这游戏长什么样"。**辨识度 = 剪影 + 色彩身份 + 形状语言 + 图标系统**，这四样目前是 0。
- 通用 CC0 素材不是原罪，**"直接拿来、不做二次加工"才是**。同样的 0x72 素材，加统一色板、描边、光照、阴影、少量重绘，可以是"复古"；原样灰阶 tint，就是"素材包演示"。
- UI 也一样：Golden UI 的框本身不难看，但**没有和游戏世界发生关系**——它可以是任何游戏的框。

**最小修复**：
1. 定一个**一句话视觉**（例："腐化森林里的午夜集市"），选 1 个主色 + 2 个辅色，所有 UI/棋盘/特效都从这 3 个色派生。
2. 给 6 个羁绊各定一个**专属色 + 专属图标形状**（兽人=獠牙/土黄，法师=星芒/青蓝，刺客=匕首/紫红……），羁绊面板、单位描边、装备标签全部复用。
3. 重绘 8–12 个**关键单位**（玩家每局都会看到的），其余用统一调色 + 描边 + 阴影批量处理；至少让"我方/敌方/精英/Boss"在剪影上能区分。
4. 加一个**标题/Logo** 和一张**主视觉**（商店页第一张图），这是"辨识度"的入口。

### ③ 信息架构是"调试器"（对应主人原话"廉价"）

**证据**：
- 文字浮空：HUD 在左上角真空区，没有容器；棋盘上方一行"拖拽棋子布阵 拖至右上出售区卖出 点开战"永久悬浮在玩法区域。
- 面板互压：抽屉压棋盘、tab 压标题、提示框压 toast、描述框压装备格。
- 文本溢出：装备名"秘银… / 甲"、"羁绊池"标题被裁掉一半、`备战 -/9` 出现非法值。
- toast 无队列：4–5 条消息在同一坐标打印，字叠字。
- 滚动条脱框：屏幕最左侧一条细线，不在任何面板里。
- 按钮无层级：开战（主操作）比出售（次操作）还小；刷新/经验是绿色边框，开战/出售是橙色边框，颜色语义不一致。

**为什么这是致命的**：
- 玩家前 10 秒的任务是"我该点哪"，不是"这游戏好不好看"。信息架构崩坏会直接把"不好看"升级成"不能用"。
- 所有这些都不是"美术问题"，是**布局基准线 + 层级规范 + 状态机**的问题；它们比换素材便宜，也比换素材见效快。

**最小修复**：
1. **一套 8px 网格**：所有面板、按钮、卡片对齐到 8 的倍数；抽屉贴边、滚动条入框、tab 进标题栏。
2. **三级文字**：标题 16px / 正文 12px / 辅助 10px（逻辑像素），中文正文 ≥12px；数字用等宽，价格右对齐。
3. **toast 队列**：最多 3 条、纵向排列、每条 ≤1 行、2 秒淡出、不覆盖抽屉和棋盘。
4. **按钮三级**：主操作（开战）最大、最亮；次操作（刷新/经验）中；危险操作（出售）最小、红色。
5. 把"拖拽棋子布阵…"那行教学字**删掉**，改成第一次进入时的高亮引导 + 图标提示；永久悬浮的教学字是最典型的"没做完"信号。

## 2.5 补课：小团队像素风怎么做到"一眼高级"（可抄的三件事）

> 结论先说：**高级感不是"画得更细"，是"光更对、色更统一、焦点更清楚"。** 两个小团队案例都证明了这一点。

### 案例 1：《风来之国》Eastward（Pixpil，6 年，十余人）
- **自研 Gii 引擎**（基于 MOAI），做了 SSAO、CRT 滤镜、LUT、延迟渲染光照、法线贴图、屏幕空间贴花、色彩校正；这些 3D 技术的核心目的不是炫技，而是解决高细节像素画最要命的问题——**视觉焦点** [来源](https://www.gameres.com/forum/t/889890)。
- **调色纪律**：控制调色板数量、保持饱和度统一；选画面最深的色阶，通过调高灰度降低饱和度，把色彩空间让给上层颜色 [同上]。
- **风格先行**：花了半年确定美术风格；角色参考赛璐璐动画；场景追求"信息密度"而不是"像素数量" [同上]。
- **可抄**：不必自研引擎，但必须做"一张 LUT + 一层光斑 + 一套统一色板"；先定风格，再画素材。

### 案例 2：《星之海》Sea of Stars（Sabotage，15→26 人）
- **2D 像素 + 3D 光照**：动态阴影、昼夜即时切换、法线贴图、体积光、水体次表面散射、环境光遮蔽；2D 物体的影子会随时间和方位变化 [来源](https://m.ithome.com/html/731810.htm)。
- **光照承担引导**：在复杂迷宫里把正确的那扇门用光源点亮，玩家自然知道往哪走；这比箭头和文字高级得多 [同上]。
- **可抄**：用"光"做引导，而不是用 UI 标注。LibGDX 里用一张径向渐变贴图 + 加法混合就能做"假光"，成本几乎为零。

### "廉价开源素材感"的五个技术成因（逐条对照本作）
| 成因 | 表现 | 本作现状 | 修法 |
|---|---|---|---|
| **混合像素密度** | 32×32 单位 + 8px 字 + 1280 画布，没有统一缩放层 | 有（640×360 虚拟分辨率，但中文 8px 糊） | 统一逻辑像素；中文 ≥12px；UI 走 2x 层 |
| **无明度结构** | 所有东西挤在 10–25% 明度 | 战斗 99.2% 像素 <20% 明度 | 10/20/25/60/85 五级明度 |
| **无光照/阴影** | 物体像贴纸，没有落地感 | 0 投影、0 环境光 | 单位落地阴影 + 棋盘内阴影 + 背景光斑 |
| **素材来源不统一** | 不同包的描边/抗锯齿/对比度混用 | 0x72 + Golden UI + 纯色方块，三种"笔触" | 统一描边 + 统一色板 + 关键单位重绘 |
| **无特效层** | 命中/合成/羁绊全无反馈 | FX 文件 0 个 | impact 三件套（闪白/hitstop/震屏） |

### 如果只有 3 件事能做（视觉侧排序）
1. **统一色板 + 明度阶梯**（1 天）：定 24 色，背景/面板/交互/文字五级明度；这一步就能把"糊"变成"清楚"。
2. **加"假光照"**（2 天）：背景垂直渐变 + 2 个径向光斑 + 单位落地阴影 + 棋盘内阴影；这一步就能把"平"变成"有空间"。
3. **加 impact 三件套**（3 天）：受击闪白、hitstop 50ms、伤害数字；这一步就能把"看动画"变成"打得爽"。

> 注意：这三件事都不需要新素材，只需要改渲染与配置；**先做这个，再谈重绘**。

## 2.6 视觉抢救顺序（两周内能看到变化）

### P0（3 天，先让它"像个游戏"）

# 第三章 与主人痛点的对账 & 给 baby 的排序建议

## 3.1 玩法痛点对账

> 原话："玩起来没有任何可以驱动我去玩下去的动力，没有 roguelike 那种紧张刺激与成长的感觉。"

| 玩家要的感觉 | 本作现状 | 缺的机制 |
|---|---|---|
| 紧张 | 3 次机会 + 败箱 + 100% 退款 + 免费刷新 + 敌人不变 | 不可逆决策、全局有限机会、可见时钟 |
| 刺激 | 25 轮直路，只有宝箱三选一 | 事件、精英战、Boss 预告、风险/回报选择 |
| 成长 | 数值 +25%、+3 熟练度/轮 | Build 质变（新羁绊机制/遗物/强化）、局外解锁新玩法 |
| 再来一局 | 无每日/无种子/无结算故事 | 短局、快速重开、复盘、每日挑战 |

**一句话**：这一版不是"内容少"，是"**结构上没有输的可能，也没有赢的惊喜**"。先把"输"做真，再把"赢"做大。

## 3.2 如果只做三件事（给排序方案用）

1. **把"暗"修掉**（3 天）：字体 12px、背景渐变 + 场景底、棋盘投影、明度阶梯。这是"看起来像不像游戏"的生死线。
2. **把"乱"修掉**（1 周）：8px 网格、三级文字、toast 队列、删空框、按钮分级。这是"像不像专业团队"的生死线。
3. **把"输"做真**（2 周）：三幕地图 + 全局 5 次机会 + 每幕 1 次不可逆强化 + Boss 预告。这是"有没有下一局"的生死线。

> 不建议现在做的事：加第 25 个棋子、加第 7 个羁绊、做皮肤、做配音。**在结构和画面都还是原型时，内容量只会放大问题。**

## 3.3 给 baby 的合并建议

- 与 claude 的玩法评审合并时，**先对齐"紧张感三件套"**：不可逆决策、可见时钟、有限机会；这三条是玩法侧的最大公约数。
- **与 claude 的分工/共识**：双方在"没有美术方向、失败无成本、成长无可见时刻、中途无意外"四点上独立收敛；claude 另查实"全游戏零音频、主菜单/选人无贴图"（代码级证据），本报告另补"24 张逐张毒评、明度/配色实测、素材管线证据、像素高级感案例"。两份不冲突，建议并列引用。
- **视觉 P0 追加一条**：至少补 3 个音效（购买/合成/命中）。claude 已查实零音频——"无声"会把"昏暗"放大一倍，玩家会同时失去视觉和听觉的焦点。
- 与主人痛点三问合并时，**视觉侧用"昏暗/无辨识度/调试器 UI"三条对齐**，玩法侧用"输得不真/赢得不大/没有下一局"三条对齐。
- 排序建议：**视觉 P0（3 天）→ 玩法 P0（2 周，地图+机会+强化）→ 视觉 P1（1 周）→ 内容扩充**。理由：视觉 P0 是"能不能被看见"，玩法 P0 是"能不能被留下"，内容扩充是"能不能被记住"。
